# Negative-Space Ledger: Banned Anti-Patterns for `git-nt` (Arch Rev 4.1)

Any pull request or slice introducing any of the following patterns MUST be rejected during Critic review.

| ID | Banned Pattern | Technical Reason Rejected | Mandatory Replacement |
|---|---|---|---|
| **AP-01** | Shared mutable flat staging file (`.git/nt_staging_dag.json`) or unclaimed staging reads | Unsynchronized read-modify-write drops/corrupts JSON spans; concurrent commits without atomic claims duplicate tombstones. | Lock-free per-event `.git/nt-stage/{id}.tmp` -> `sync_all()` -> atomic `rename(2)` -> `.json`, plus atomic `{id}.claimed-{pid}` claim on promote/commit. |
| **AP-02** | Embedded SQLite WAL (`rusqlite`, `libsqlite3-sys`) or any C-backed `*-sys` crate | Pulls in a C compiler toolchain, breaks zero-C pure-Rust builds, and bloats release binaries. | Pure-Rust `std::fs` atomic staging + pre-approved zero-C crates only. |
| **AP-03** | Direct Git commit or loose-blob synthesis via a library (bypassing native `git commit`) | Bypasses GPG/SSH signing and user `pre-commit` hooks; risks loose objects vulnerable to `git gc`. | Delegate commits to native `git commit` and reads to hardened native `git` behind `nt_read::RepoReader`. |
| **AP-04** | Single mutable tracked log file (`.promptlog.jsonl`) OR unsigned out-of-band Git notes (`refs/notes/...`) as primary trusted memory | A single append log causes constant merge conflicts; unsigned Git notes bypass PR review and commit signing (L1 checks the commit, not the note ref), break `git pull` on non-forced fetch divergence, and require fragile rewrite reconcilers. | Immutable per-event tracked files at `.nt/ns/{id}.json` (zero merge conflicts, reviewed & signed with code, native rewrite/squash survival), read strictly from the trusted ref's Git tree (`refs/heads/main`). |
| **AP-05** | Storing raw Tier 3 `<think>` logs or compressed reasoning blobs in the repository | Bloats repository clones and risks pushing echoed secrets to remotes. | Keep raw `<think>` traces strictly local and Git-ignored (`.nt-local/`); persist only `local_think_digest` (`sha256:`). |
| **AP-06** | Static XML/Markdown wrappers (`<nt_note>`), reading working-tree files on hydrate, denylist-only Unicode checks, unanchored secret prefixes (`sk-`), or stripping bare `<`/`>`/`\`` | Static wrappers allow breakout; working-tree reads allow untrusted PR injection; unanchored `sk-` corrupts `task-queue`; stripping `<`/`>` destroys Rust generics (`Vec<u8>`, `->`). | L1 trusted-ref Git tree + optional signature gate; L2 plain-Rust control/Bidi/Tag/Variation-Selector filter + anchored `regex-lite` + fence/boundary-tag neutralization preserving code syntax; L3 128-bit CSPRNG Spotlighting. |
| **AP-07** | Exposing write, stage, promote, commit, retire, or shell tools over MCP — or letting `nt-mcp` depend on `nt-write` | Expands read-only MCP blast radius into repo mutation or command execution. | Compile-time isolation: `nt-mcp` depends ONLY on `nt-core` and `nt-read`, registering `nt_hydrate_file` exclusively. |
| **AP-08** | Relying on `serde_json` struct declaration order or default `BTreeMap` for RFC 8785 JCS | Struct fields serialize in declaration order (not sorted), and Cargo `serde_json/preserve_order` feature unification silently breaks key sorting; UTF-8 order differs from RFC 8785 UTF-16 order above `U+FFFF`. | Dedicated recursive RFC 8785 JCS serializer (`to_jcs_bytes`) with explicit UTF-16 code-unit key sorting and golden byte-identical test vectors. |
| **AP-09** | Git hooks executing repo-relative binaries (`$(repo)/target/release/git-nt`) or writing to `stdout` in MCP mode | Executing repo-controlled paths turns `rebase`/`checkout` into RCE; writing logs to MCP `stdout` corrupts JSON-RPC framing. | Resolve binaries strictly from `PATH` or explicit user config; write all MCP diagnostics strictly to `stderr`. |
| **AP-10** | Premature v5.0 or unrelated scope creep (Firecracker VMs, vector DBs, Rekor logs, LoRA/DPO training, `zkTLS` human-policing, premature `gix` or Agent Trace line-blame before pilot validation) | Destroys minimalist `< 3 MiB` focus before single-repo Negative-Space efficacy is empirically proven. | Strictly excluded from v0.1; gated behind Phase 1 pilot and Phase 4 release thresholds. |

> **Deferred LLM-Extractor Note (not applicable to v0.1 Rust crates):** If a future local-model Critic extractor is built outside v0.1, never force zero-whitespace GBNF at `T=0.0` inside `<think>` blocks; sample reasoning freely (`T=0.6`), decode structured verdicts at `T=0.0`, and canonicalize via RFC 8785 JCS in Rust.
